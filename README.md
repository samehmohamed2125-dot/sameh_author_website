# الموقع الرسمي للكاتب سامح محمد عبد الظاهر

موقع عربي RTL بتصميم أدبي متجاوب، لعرض الكاتب وكتابه «بعض مني ومنك — عن النفس وما لا يراه أحد» بسعر 400 جنيه مصري. الغلاف مساحة مؤقتة، والمقتطفات فارغة حتى إضافة النصوص الأصلية. لم تُضف معلومات شخصية أو وسائل تواصل غير معتمدة.

## التشغيل

يتطلب Node.js **24.19.0** (فرع 24). لا توجد اعتماديات خارجية أو خدمات مدفوعة أو مفاتيح API.

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm test
npm run build
npm run dev
```

يفتح الخادم محليًا على المنفذ 3000. للإنتاج: `npm start`. لتحميل إعداد محلي اختياري، انسخ `.env.example` إلى `.env` ثم استخدم `node --env-file=.env src/server.js`؛ أو حقن المتغيرات من منصة النشر. أمر `npm start` لا يقرأ `.env` تلقائيًا.

## البنية وتعديل المحتوى

- `src/content.js`: الاسم والسيرة والكتب والأسعار والمقتطفات وعناوين السياسات. حافظ على معرف ثابت وفريد لكل كتاب. أضف كتابًا إلى المصفوفة لإظهاره تلقائيًا في المكتبة؛ يظهر الكتاب الأول في المقدمة.
- `src/render.js`: HTML من الخادم، مستقل عن JavaScript للقراءة والتنقل، مع ترميز المحتوى لحماية العرض.
- `public/styles.css`: تصميم Mobile-first، خصائص RTL، حالات تركيز وإعداد تقليل الحركة. الخط العربي يستخدم Amiri أو Noto Naskh Arabic إذا توفر محليًا، مع بدائل نظام؛ لا طلبات خطوط خارجية. يمكن لاحقًا تضمين خط عربي مرخّص محليًا مع ملف ترخيصه.
- `public/app.js`: نافذة الطلب، إدارة التركيز، وإعلان الحالة لقارئ الشاشة.
- `src/commerce.js`: الحد الفاصل الخادمي للشراء المستقبلي.
- `src/seo.js` و`src/site-config.js`: عنوان الموقع القانوني وأصول المشاركة والهوية.
- `src/server.js`: الخادم وواجهات API والترويسات الأمنية.
- `scripts/build.js`: صفحات ثابتة في `dist/`، مفيدة للمعاينة والنشر الثابت.
- `tests/`: اختبارات HTTP والمحتوى وSEO وحدود الشراء.

ضع **الغلاف الأصلي** في `public/` واضبط `cover` في بيانات الكتاب مثل `/book-cover.webp`. لا تضع النسخة الإلكترونية للكتاب هنا. لإضافة favicon أو صورة مشاركة أصلية، ضع الملفات في `public/` وحدّث `src/site-config.js`. الأصول المرئية مسموحة بمسارات محلية محددة فقط. أضف مقتطفات معتمدة إلى `excerpts`؛ لا توجد اقتباسات مختلقة.

## الشراء والدفع والتسليم

الشراء **غير مفعّل**. النافذة تعرض الكتاب والسعر وتسمح بالتحقق من الإتاحة، دون جمع معلومات العميل. `POST /api/orders` يعيد 503 للكتاب الصحيح و400 للمعرف الخاطئ؛ السعر مصدره الكتالوج الخادمي. لا يُنشأ طلب ولا يُخصم مبلغ ولا يعلن الموقع نجاح الدفع.

عند الربط الفعلي، يلزم تنفيذ:

1. قاعدة بيانات للطلبات بحالة pending ومعرف فريد، وتخزين السعر والعملة من الخادم.
2. إنشاء جلسة بوابة الدفع من الخادم وإبقاء الأسرار في إعدادات النشر.
3. webhook موثّق بتوقيع البوابة، مع مطابقة الطلب والمبلغ والعملة والتحقق من العملية عند المزود ومنع تكرار المعالجة.
4. تحويل الحالة إلى paid بعد التأكيد الخادمي فقط؛ إعادة توجيه المتصفح أو حدث الواجهة ليسا دليل دفع.
5. حفظ الكتاب في تخزين خاص خارج `public/` و`dist/` والمستودع، وإصدار روابط قصيرة العمر بعد التحقق من استحقاق الطلب، مع ضبط المعدل والسجلات والتنبيهات.
6. اعتماد السياسات وتفاصيل التنسيق والتسليم والاسترجاع والدعم قبل تمكين البيع.

لا يوجد endpoint تسليم أو دفع وهمي. واجهة الطلب تقبل JSON محدودًا بـ4 كيلوبايت وتمنع المصادر الخارجية؛ يجب ضبط `SITE_URL` ليطابق المصدر الحقيقي. هذه الأسس لا تغني عن مراجعة أمنية عند إضافة معالجة أموال وبيانات شخصية.

## SEO والتحليلات

اضبط `SITE_URL` إلى النطاق الحقيقي HTTPS قبل بناء الإنتاج أو تشغيله. metadata عربية، canonical، Open Graph، Twitter card وSchema.org من نوع Person وBook وWebSite. لا تُعلن إتاحة شراء وهمية في Schema. `sitemap.xml` يتضمن الرئيسية والمقالات المعتمدة فقط؛ السياسات المسودات و404 تستخدم noindex. أزل noindex عن السياسات وأضفها للخريطة بعد اعتمادها.

`measure()` يطلق أحداثًا محلية فقط دون ملفات ارتباط أو إرسال بيانات أو معرفات مستخدم. يمكن ربطه لاحقًا بمزود تحليلات بعد تحديد الخصوصية والموافقة. قياس الشراء المؤكد يجب أن ينشأ من حدث الخادم الموثوق، مع منع التكرار، وليس زر الواجهة. لا يوجد تتبع مفعّل حاليًا.

## التحقق

`npm test` يشغّل الاختبارات المتاحة تشمل المحتوى والسيرة كما قُدّمت، RTL، جميع الصفحات والأصول، 404، Schema، السعر الخادمي ورفض JSON الخاطئ والمصادر الخارجية والطلبات الكبيرة. `npm run build` يولد الرئيسية والمقالات المعتمدة والسياسات الأربع و404 وSEO والأصول.

راجع يدويًا قبل الإطلاق على هاتف بعرض 320 و375 و768 بكسل وعلى سطح المكتب؛ اختبر التنقل بلوحة المفاتيح وEscape وإعادة التركيز بعد إغلاق نافذة الطلب، قارئ الشاشة والتكبير 200%. لم تُجرَ اختبارات متصفح آلية ضمن المشروع؛ اختبارات HTTP لا تثبت التوافق البصري على كل جهاز.

## النشر

النشر الموصى به: استضافة تدعم Node.js 24 خلف reverse proxy بشهادة HTTPS. حقن `SITE_URL=https://your-real-domain` و`HOST=0.0.0.0` و`PORT` حسب المنصة، ثم `npm ci` و`npm test` و`npm run build` و`npm start`. لا تعتمد على بقاء عمليات التطوير بعد استعادة البيئة. اضبط مراقبة الخدمة وإعادة التشغيل وحدود الطلبات في الوكيل.

يمكن نشر `dist/` على استضافة ثابتة مع تهيئة صفحة 404 لتعيد حالة 404 الفعلية. **التحقق من الشراء يحتاج خادم Node**؛ في النشر الثابت سيظهر تعذّر الاتصال ولن يحدث أي دفع. بوابة الدفع المستقبلية تستلزم backend فعليًا. لا تعرّض سورس الخادم أو `.env` أو بيانات الطلبات كأصول عامة.

قبل الإطلاق: أضف الغلاف والتواصل والأصول الأصلية، راجع السياسات قانونيًا، اضبط النطاق واختبر HTTPS وSEO وإمكانية الوصول. التطبيق قابل للتطوير حاليًا لكنه ليس جاهزًا لقبول مدفوعات حقيقية.

## النسخ الاحتياطي

احفظ الكود وملف القفل في Git ونسخة مشفرة مستقلة من الأصول الأصلية. لا تُحفظ الأسرار أو بيانات المشترين أو ملفات الكتاب الخاصة في Git. بعد إضافة قاعدة بيانات وتخزين خاص، نفّذ نسخًا دورية مشفرة خارج الخادم، وحدد مدة الاحتفاظ والصلاحيات، واختبر استعادة نسخة على بيئة معزولة. حاليًا لا توجد قاعدة بيانات أو طلبات أو بيانات عملاء، و`dist/` قابل لإعادة البناء.

## المقالات: من كتاباتي

البيانات مستقلة في `src/articles.js`. المقال «النخل لا يستعجل البلح» مكتمل بنصه المنقول من الصورة الأصلية وتوقيع الكاتب فقط، دون الملاحظة الصغيرة أسفل الصورة، وبغلافه الفني المعتمد المحفوظ كما هو. يظهر في «من كتاباتي» ورابطه الثابت `/writings/al-nakhl-la-yastaajil-al-balah`، ويدخل sitemap وملفات البناء. أي مقالات بحالة `draft` لا تظهر كبطاقات ولا تُقدَّم كصفحات، وروابطها تعيد 404 مع noindex. لا يوجد نص تجريبي منشور.

لإكمال مقال بعد اعتماد الكاتب: أضف النص الحرفي إلى `paragraphs` (عنصر لكل فقرة)، وأضف الصورة المعتمدة في `public/images/articles/` وحدد `cover` بخصائص `src` و`width` و`height` و`alt`. يمكن إضافة صورة النص الأصلي في `originalTextImage` بنفس الخصائص؛ تُعرض كاملة مع رابط تكبير. ضع وصف SEO معتمدًا في `description` أو اتركه فارغًا لاستخدام الفقرة الأولى. لا تغيّر `status` إلى `published` إلا بعد اعتماد النص والصورة؛ يلزم أيضًا اكتمالهما حتى يظهر المقال. لا تغيّر `slug` بعد النشر للحفاظ على روابط المشاركة.

البطاقات وصفحات المقالات والخريطة والبناء تتبع قائمة المقالات المعتمدة تلقائيًا. الغلاف يعرض كاملًا داخل إطار 16:9 دون قص. المشاركة تدعم مشاركة الرابط أو نسخه، مع رابط قابل للتحديد عند غياب دعم الحافظة. نفّذ الاختبارات والبناء وأعد تشغيل الخدمة بعد تعديل بيانات المقالات؛ مسارات الخادم تُجهّز عند بدء التشغيل.
